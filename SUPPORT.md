# Support

PickerMux is a community-maintained project without a paid support commitment
or guaranteed response time.

## Before asking for help

1. Read the [README](README.md) and
   [troubleshooting guide](docs/TROUBLESHOOTING.md).
2. Confirm that you are using the latest release.
3. Record `pickermux --version`.
4. Run `pickermux status` and `pickermux doctor`.
5. Reproduce the issue with the smallest possible configuration.
6. Remove credentials, account identifiers, cookies, private prompts, local
   usernames, capability paths, and unrelated file paths from all output.

For installer failures, also state whether the failure occurred during
preflight, download, checksum verification, archive validation, or setup. Never
upload the private installation receipt or bypass a failed checksum to obtain
more diagnostic output.

## Where to go

- Use the GitHub bug-report form for a reproducible defect.
- Use the feature-request form for a focused improvement proposal.
- Use a GitHub Discussion for usage questions when Discussions are enabled.
- Follow [SECURITY.md](SECURITY.md) for suspected vulnerabilities. Never report
  a vulnerability in a public issue or discussion.

Questions about Codex account access, native model entitlements, or billing
belong to OpenAI support. Questions about LM Studio installation, model
downloads, or server behavior belong to LM Studio support. PickerMux cannot
grant access to either product or change their account state.
